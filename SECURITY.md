# Security

For a vulnerability involving account data, arbitrary file access, command execution or update verification, use GitHub's **Security → Report a vulnerability** for this repository. Do not post exploit details or private data in a public issue while a fix is being prepared.

Include the affected release, a minimal reproduction, impact and relevant redacted diagnostics. Never attach signing keys, credentials, personal backups or whole Android phone images.

Security fixes target the latest release. Older versions may require an update. Velox's signed update channel is separate from Windows Authenticode; current Windows binaries do not have a publisher certificate.

Root is optional and changes Android's security model. Backups are unencrypted. Store them privately. Android, Google Play, games and controller drivers have their own security and compatibility requirements.
