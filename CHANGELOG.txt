2.3.0 | 2026-11-07
[New]
- A dark Velox installer with English/German setup, optional desktop shortcut and data-preserving uninstall.
- Hands-off first-run startup and language defaults, with an optional main-phone auto-start setting.
- English and German for desktop Velox, Home, Settings and controller tools, with per-phone language sync.
- Screen resolution shortcut in the phone toolbar.
- Velox Instances: create and run independent phones together with a shared SDK, separate apps/accounts/saves/controls, and individual start, stop and controls windows.
- Combined CPU/RAM allocation checks, unique connection ports and verified process ownership keep simultaneous phones separate.
- Velox Vault: verified cold phone backups, staged recovery into a separate phone, Undo restore and interrupted-recovery rollback.
- Per-game presets for display, 30-144 FPS, CPU, memory, graphics and fullscreen, with a restart review and separate global settings.
- Controller Studio: Xbox-compatible and DirectInput controllers, native non-root Android gamepad input, touch buttons/sticks, dead zones, sensitivity and camera-Y inversion.
[Improved]
- Hardware-aware 48/64 CPU and RAM choices, disabled unsupported allocations, separate physical/logical CPU counts and safe lower-host resolution.
- Recommendations consider the active desktop resolution/refresh, GPU memory type, available RAM and other running phones.
- Four individually designed Velox-chan wallpapers with everyday clothes, fine anime linework and atmospheric scenes: After Hours, Blue Hour, Stargazer and Windowlight.
- Recovery stays accessible when phone data is missing but a matching Android SDK is available.
- Sidebar spacing accommodates Recovery without overlapping the phone status panel.
[Fixed]
- Clean dark text fields without gray cue-banner backgrounds or duplicate search text.
- Android CPU limits are detected after boot; unsupported allocations are disabled and resource reservations corrected.
- First-run setup language and existing-SDK actions no longer overlap.
- A matching window title or port alone can no longer make Velox adopt an unrelated emulator process.
- Concurrent phone backups have unique names, and large backup checksum operations respond to cancellation between reads.
- Recovery paths support non-English folder names; prepared disk files stay protected until activation and locks release after failures.
- Recovery rejects unsafe file paths, changed payloads, unmatched Android images and unexpected disk backing chains.
- Restores retain Android's system-image identity marker so the emulator preserves their writable disks and installed apps.
- Phone numbers loaded from settings or backups are validated before building emulator arguments.
- Guest disk writes are flushed before the phone stops.
- The optional Windows hypervisor setup resolves DISM from the Windows system directory.

2.2.0 | 2026-11-06
[New]
- High-end allocations up to 64 virtual CPU cores and 64 GB RAM, with host limits and memory reserved for Windows. Auto remains conservative.
[Fixed]
- The native emulator toolbar no longer overlaps Velox controls; detection handles Qt's actual window title and delayed window creation.
- Native controls return when the custom toolbar is turned off or Velox closes, and stay hidden while the phone is minimized.
- Missing Android configuration folders are created and checked before launch, preventing a first-start error loop.
- Excessive startup logging stops the failed phone; diagnostic reads are bounded and oversized logs cannot authorize snapshot resume.
- Setup checks extraction-job configuration and thread startup failures before continuing.
- Completed setup refreshes Android discovery on the UI thread, avoiding concurrent path updates.
- Toolbar tooltips return after the phone restarts; explicitly showing native controls places them beside Velox controls.
[Improved]
- First-time setup validated with fresh Google downloads, a separate SDK/profile/AVD and only Windows system tools on PATH.
